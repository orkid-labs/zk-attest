# zk-attest

zk-attest is a backend service for issuing ZK-backed credentials on Hedera: attestations are proven off-chain, anchored to HCS (Consensus Service) audit logs, and delivered as HTS NFTs. Proof quality is scored by the negentropy energy model.

## When to use

Standing up a verifiable-credentials service on Hedera, or studying ZK + HCS integration patterns.

## Install

```
cargo install zk-attest
```
